# gem-packaging Specification

## Purpose
What the packaged `audioproxy-rails` gem guarantees about its own shape: gem name and namespace layout, loadability without Rails, railtie presence when Rails is available, absence of engine artifacts, and a green test harness.

## Requirements
### Requirement: Plugin-shaped gem skeleton
The repository SHALL contain a gem skeleton generated by `rails plugin new` in its plain (non-mountable, non-full) form: gemspec, `lib/`, Minitest wiring, and a `test/dummy` Rails application — and SHALL NOT contain engine artifacts (no `app/`, no routes, no migrations, no `isolate_namespace`).

#### Scenario: Skeleton shape
- **WHEN** the repository is inspected after scaffolding
- **THEN** `audioproxy-rails.gemspec`, `lib/audioproxy.rb`, and `test/dummy` exist, and no `app/` directory or `config/routes.rb` exists at the gem root

### Requirement: Gem loads without Rails
`require "audioproxy"` SHALL succeed in a plain Ruby process with Rails absent, and the gemspec SHALL NOT declare Rails as a runtime dependency.

#### Scenario: Rails-free load
- **WHEN** `ruby -Ilib -e 'require "audioproxy"'` runs without Rails installed in the load path
- **THEN** it exits successfully and defines `Audioproxy` but no `Rails` constant

### Requirement: Railtie registers under Rails
When loaded inside a Rails application, the gem SHALL contribute a railtie (an `Audioproxy::Rails::Railtie`), and the dummy app SHALL boot with it registered.

#### Scenario: Dummy app boot
- **WHEN** the `test/dummy` application initializes in the test suite
- **THEN** boot succeeds and the gem's railtie is among the application's railties

### Requirement: Namespace split between core and Rails layer
Core code SHALL live under the top-level `Audioproxy` namespace (including `Audioproxy::VERSION`), and Rails-facing code under `Audioproxy::Rails`; no file under the core namespace SHALL reference Rails constants.

#### Scenario: Version constant
- **WHEN** the gem is loaded
- **THEN** `Audioproxy::VERSION` is defined

### Requirement: Test task runs green
`rake test` (or `bin/test`) SHALL run the Minitest suite successfully on the scaffolded repository.

#### Scenario: Green scaffold suite
- **WHEN** `rake test` runs after scaffolding and trimming
- **THEN** it exits zero
